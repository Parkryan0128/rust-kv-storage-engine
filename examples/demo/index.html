Why this workload?

A larger existing dataset is followed by small updates to 128 keys. This makes repeated rewriting of cold data visible.

What is the tradeoff?

Size tiers can retain more old versions and use more disk space. Reads may need more work. Lower write volume is not a universal speedup.

What is measured?

SST output bytes since opening, including seeding. WAL, manifest and device amplification are excluded. Values are checked after each batch.
